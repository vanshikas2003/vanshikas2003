## Projects I'm Proud Of

**Tech:** Python, FastAPI, WebSockets, Pydantic

### Dark Web Threat Intelligence for Economic Risk Analysis
**Tech:** Python, Scapy, Tor, BeautifulSoup

**Tech:** Solidity, Web3.js, Node.js
